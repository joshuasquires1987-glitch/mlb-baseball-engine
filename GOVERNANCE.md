# Governance

- v1.1 is production authority.
- v1.2-RC1 is shadow-only.
- Prices are forbidden from probability construction.
- Only explicit user confirmations count as wagers.
- Shadow predictions never affect bankroll, wager ledger, W/L, P/L, ROI, or selection.
- Frozen predictions preserve model version, probability, timestamp, and integrity state.
- Model mutation is never automatic.
