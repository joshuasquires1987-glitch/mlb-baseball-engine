# First Real Probability Gate

A live game may not be labeled a real production probability until both conditions are true:

1. starter-role integrity is green for both sides
2. strictly pregame starter, team, and bullpen histories are attached

This gate caught an important Aug. 9 case:
- CIN@WSH has named probables, but Brad Lord is returning from an IL/rehab stretch and is being discussed as an opener/bullpen-game workload.
- The engine must not apply a normal starter-depth assumption to that matchup.

The clean first rehearsal candidate is NYM@PIT:
- Sean Manaea: conventional starter
- Jared Jones: conventional starter

The runtime history fetcher uses MLB Stats API game-log endpoints. Sportsbook prices remain excluded until after the probability is frozen.
